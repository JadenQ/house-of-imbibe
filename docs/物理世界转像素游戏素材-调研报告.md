### 📊 需求契合度打分（5 分制）

| 需求 | 契合度 | 说明 |
|---|---|---|
| 块大小 / 分辨率可调 | ⭐⭐⭐ | ❌ 2026-08-01 下调：**无块大小参数**；分辨率可调但有 128/256/320 的硬上限 |
| 清晰度可控 | ⭐⭐⭐⭐ | `text_guidance_scale` 1–20 可调，但非"清晰度"独立轴 |
| 2D 俯视角宝可梦风 | ⭐⭐⭐⭐⭐ | `view: "low top-down"` 直接对口，sprite sheet 一站搞定 |
| 双层 LOD（远/近） | ⭐⭐⭐ | ❌ 2026-08-01 下调：**不能"一次出多分辨率"**。每个尺寸都是独立一次付费调用 |
| Web 端 | ⭐⭐⭐⭐⭐ | 本身就是 Web 工具 |
| AI 风格迁移（可选） | ⭐⭐⭐⭐⭐ | Bitforge 模型支持参考图风格迁移，可关闭只取纯像素路径 |
| API 可调用 | ⭐⭐⭐⭐⭐ | REST v2 + Python SDK 齐全 |
| **MCP 集成** | ⭐⭐⭐⭐⭐ | **官方 MCP server，65 个工具**。⚠️ 但仅限开发期，见下方警告 |

> ⚠️ **2026-08-01 补充的关键限制**：以上打分是"功能契合度"，不等于"能一键给终端用户用"。
> 实际接入有三个硬约束：**(1)** 生成端点是**异步**的，端到端 5–9 分钟；
> **(2)** 最短路径需 **2 次调用 + 2 轮轮询**，没有单端点一步到位；
> **(3)** **MCP 不能用于面向用户的网页**（浏览器无 MCP 客户端，且会暴露 token）。
> 详见 [`reference/pixellab-api.md`](./reference/pixellab-api.md)。

### 🎯 结论

**PixelLab.ai 在功能契合度上是当前最优解**——同时满足"俯视角 sprite + 多方向 + 动画帧 + API + MCP"，其他开源项目没有任何一个能匹敌。所有短板（MCP、客户端兼容性、风格迁移开关）官方都已覆盖。

### 🔌 MCP 详情（官方支持）⭐ 关键发现

> 官方页面：[pixellab.ai/mcp](https://www.pixellab.ai/mcp) — "Vibe Coding AI Toolkit"

**MCP 端点**：`https://api.pixellab.ai/mcp`
**鉴权**：Bearer Token（API Secret）
**文档**：`https://api.pixellab.ai/mcp/docs`

**一键安装（Claude Code）**：
```bash
claude mcp add pixellab https://api.pixellab.ai/mcp -t http \
  -H "Authorization: Bearer YOUR_SECRET"
```

**支持的客户端（15+）**：

| 类型 | 客户端 |
|---|---|
| IDE | VS Code / Cursor / Windsurf / Zed / Junie |
| CLI | Claude Code / Droid / Gemini CLI / Codex CLI / Warp |
| App | Claude Desktop / BoltAI / LM Studio / Perplexity Desktop / Kiro |
| Extension | Cline / Continue |
| Universal | STDIO-only / 其他 MCP 客户端 |

**7 个 MCP 工具**  <!-- ❌ 2026-08-01 实测：65 个工具，完整清单见 reference/pixellab-api.md §九 -->

| 工具 | 用途 | 示例参数 |
|---|---|---|
| `create_character` | 创建 4/8 方向角色 | `description="cute wizard", n_directions=8` |
| `animate_character` | 给已有角色加动画 | `character_id="abc123", animation="walk"` <!-- ⚠️ 参数名实为 template_animation_id 或 action_description，无 animation 参数 --> |
| `create_topdown_tileset` | Wang tileset 地形拼接 | `lower="ocean", upper="beach"` <!-- ⚠️ 实为 lower_description / upper_description --> |
| `create_sidescroller_tileset` | 平台游戏 tileset | `lower="stone brick", transition="moss"` <!-- ⚠️ 实为 lower_description / transition_description --> |
| `create_isometric_tile` | 等距 tile | `description="grass on top of dirt", size=32` |
| `create_map_object` | 地图物件（透明背景，支持风格匹配） | `description="oak tree", background_image={base64}` |
| Raw Images (5 子工具) | 图生图 / 编辑 / 修复 / 动画 | `create_image_pixflux/pixen/pro`, `edit_image`, `inpaint_image`, `animate_image` |

> ❌ **2026-08-01 更正**：MCP **不能用于本项目的用户侧生成功能**。它是给你在
> Claude Code / Cursor 里做素材的开发期工具。用户的浏览器里没有 MCP 客户端，
> 且把 token 下发到前端等于把余额交给所有人。**用户侧必须走 REST v2 + 自建后端代理**。

**对你需求最关键的路径**（2026-08-01 修正版）：

1. **路径 A（推荐）**：`POST /v2/create-character-with-4-directions` → 轮询 →
   `POST /v2/animate-character`（`template_animation_id="walking-4-frames"`）→ 轮询。
   ≈ $0.14（template 动画）或 $0.062（v3 动画），5–9 分钟
2. **路径 B（照片入口）**：`POST /v2/portrait-character-pro` → `POST /v2/create-character-v3`
   → `POST /v2/animate-character`。≈ $0.19–0.30，6–11 分钟
3. ❌ **`image-to-pixelart` 不是照片转 sprite 的入口** —— 它只做降采样像素化，
   产出无法作为 `create-character-v3` 的朝南参考图

## 三、完整方案矩阵（含 PixelLab）

### 🅰️ PixelLab 主导方案 ⭐ 推荐

```
人物原图 / 文字描述
        │
        ▼
┌─────────────────────────────────┐
│  PixelLab.ai (Web + Python SDK) │
│                                 │
│  • image_size: 48×48 / 64×64    │
│  • text_guidance_scale: 1–20    │
│  • view: "low top-down"         │
│  • 4 或 8 directions            │
│  • Animations: walk/idle/...    │
│  • color_image + force_colors   │
│    → 锁 GBA 调色板               │
└─────────────────────────────────┘
        │
        ▼
   sprite sheet (PNG) + ZIP 导出
        │
        ▼
  Tiled → Phaser/Godot → 游戏
```

     Block Size 8–16 / Guidance Scale 7–12 / Projection Top-Down / Rotations 8" 有多处错误：

**优点**：一步到位、效果最接近绿宝石风、可直接出 sprite sheet
**代价**：付费 API；**异步分钟级**（非实时）；每方向单独计费
**适用**：愿意为质量付费、要快速出活

### 🅱️ 开源自建方案（备选/离线）

```
前端: image2pixel-web (fork)
        │
        ├──> 纯算法: Image2Pixel + GBA 调色板 + 抖动
        │            → Tier 1 远景 (64×96)
        │
        └──> AI 可选开关 → Replicate ostris/image-to-pixel-art
                            ↓
                          Tier 2 近景 (256×384)
        │
        ▼
   sprite + map tiles
        │
        ▼
  Tiled → Phaser → 游戏
```

**优点**：完全免费、可定制、隐私可控
**代价**：AI 效果不如 PixelLab、需要自己拼

### 🅲 混合方案（折中）⭐ 推荐用于 MVP

```
人物原图
   │
   ├─ Tier 1 远景 ─> 开源 Image2Pixel（快、免费、可批量）
   │
   └─ Tier 2 近景 ─> PixelLab.ai Python SDK（效果好、按需付费）
```

**优点**：免费档负责场景/批量，付费档只用在关键人物头像上，成本可控
**代价**：需要维护两套管线

## 四、最终推荐路线

### 🚀 Phase 1（1–2 天，验证方向）

1. 上 [pixellab.ai](https://www.pixellab.ai/) 注册试用
2. 用自己照片跑一次 Top-Down preset + 8 方向旋转 + walk 动画
3. 验证是否满足"绿宝石远景 + 辨识五官近景"双层需求
4. 同步试用 [image2pixel.app](https://image2pixel.app/) 做免费档对照

### 🚀 Phase 2（3–5 天，搭骨架）

1. **接入 PixelLab MCP** —— **仅用于你自己在编辑器里做素材**（官方，零成本）：
   ```bash
   # Claude Code / Cursor 等一键安装
   claude mcp add pixellab https://api.pixellab.ai/mcp -t http \
     -H "Authorization: Bearer YOUR_SECRET"
   ```
   装完后 Claude 直接能用 `create_character`、`create_map_object` 等工具生成素材。
   ❌ **但用户侧的"页面内生成"不能走这条路** —— 见 §二 的警告。

2. **用户侧生成走 REST v2 + 自建后端代理**（2026-08-01 修正，替代原"前端对接 MCP"方案）：
   - Rust 后端持有 token，暴露自己的 `/api/generate` 系列接口
   - `pixellab_jobs` 表 + tokio 后台 worker 轮询（5–10 秒间隔）
   - 前端 SSE / 轮询自家状态接口，产物落 `object_store`
   - 完整设计见 [`reference/pixellab-api.md`](./reference/pixellab-api.md) §十一

3. **Python SDK 备选**（如需程序化批量）：
   ```python
   import pixellab
   client = pixellab.Client(secret="YOUR_API_TOKEN")

   # 4 方向角色（异步，需轮询）
   response = client.create_character_with_4_directions(
       description="chibi bartender in green apron, pokemon emerald style",
       image_size=dict(width=48, height=48),
       view="low top-down",
       text_guidance_scale=9.0,
   )
   ```

   <!-- ❌ 2026-08-01：原示例是编造的，不可运行。错在：
        (1) client.generate_image() 不存在于本用途；构造函数是 Client(secret=...) 不是 Client(api_key=...)
        (2) block_size 参数不存在
        (3) guidance_scale 应为 text_guidance_scale
        (4) image_size 256×384 超上限且非方形
        (5) 缺少最关键的事实：这是异步端点，必须轮询 -->

> ⚠️ **Python SDK 仅适合你本地批量出素材**。项目后端是 Rust，用户侧请用 `reqwest`
> 直打 v2 REST。**JS SDK 不要用** —— 它仍指向已废弃的 v1 API。

### 🚀 Phase 3（1 周，集成到游戏）

1. PixelLab 输出 sprite sheet → 切帧 → 导入 Phaser
2. Tiled 做地图，铺俯视角关卡
3. Phaser 加载人物 + 地图，跑通"现实人物走进像素世界"流程

## 五、关键风险 & 缓解

| 风险 | 缓解策略 |
|---|---|
| ~~PixelLab 定价不透明~~ | ✅ 2026-08-01 已解除：定价公开且按端点/尺寸列明 |
| API 配额限制 | 按次计费，`GET /v2/balance` 做低余额告警；每用户生成次数限额；非关键场景降级到本地算法 |
| **生成耗时 5–9 分钟** | ⚠️ 2026-08-01 新增风险：**不能做同步 UI**。落库 + 后台 worker + SSE 通知；文案明示预计耗时 |
| **每方向单独计费** | ⚠️ 2026-08-01 新增：4 方向动画 = 4 次收费。template 模式比 v3 贵 2.5 倍，MVP 阶段优先 v3 |
| **token 泄露** | ⚠️ 2026-08-01 新增：CORS 允许前端直连，**但必须走后端代理**，否则余额被刷 |
| GBA 手绘感难复刻 | `color_image` + `force_colors: true` 传绿宝石调色板；后期人工修色块衔接 |
| 肖像权 | 加用户授权开关 + 不持久化上传图 |
| 双层 LOD 切换突兀 | 用 Phaser 的 tween 做缩放过渡动画。⚠️ 注意每个 LOD 尺寸都是独立付费调用 |
| 产物 URL 时效 | PixelLab 返回的 URL 不当长期资产，`reqwest` 拉回落 `object_store` |

## 总结（一句话）

> **PixelLab.ai 功能上满足需求，但不是"一键"** —— REST v2 + Python SDK + 官方 MCP（65 工具）
> 三路可用，`view: "low top-down"` 直击绿宝石风，`create-character-with-4-directions`
> 出多方向 sprite。**但生成是异步的（5–9 分钟）、最短需 2 次调用 + 2 轮轮询、
> MCP 只能开发期用、用户侧必须自建后端代理。**
> **Phase 1 验证审美、Phase 2 搭后端代理 + 任务表、Phase 3 集成进 Phaser。**
