Then in the project root:

```bash
cargo run --bin pixelart_server --release
```

Wait ~90 s for the first release build, then open:

> **http://localhost:8081**

Drop a PNG/JPEG/WEBP/GIF into the box, pick **single image** or **4-dir character**, click **Generate**.

- **Single image**: sync, ~5–10 s. Returns vision description + a pixel-art PNG.
- **4-dir character**: async, ~60–120 s (PixelLab takes a while to draw 4 directions). The UI polls every 3 s and shows the 4 direction sprites when ready.

Test cost: **~$0.013 per 4-dir character** (1 PixelLab generation + 1 vision call). Single image: ~$0.009.

All output goes to `pixellab-out/` (override with `PIXELLAB_OUT=...`).

| File | What it is | How it was made |
|---|---|---|
| `pixellab-out/pixon-256px.png` | Orange tabby cat, 256×256 RGBA, 38 KB | CLI: `image2pixel text "..."` — text-only, no LLM in the loop |
| `pixellab-out/direct-256px.png` | Red panda → pixel-art, 256×256 RGBA, 47 KB | CLI: `image2pixel direct test-red-panda.png` — PixelLab direct, no LLM |
| `pixellab-out/avatar-test-red-panda-64px/east.png` | East-facing sprite, 92×92 RGBA, 2 KB | **Full new pipeline**: image → MiniMax-M3 vision → text → PixelLab 4-dir character |
| `pixellab-out/avatar-test-red-panda-64px/west.png` | West-facing sprite, 92×92 RGBA, 2 KB | ↑ same |
| `pixellab-out/avatar-test-red-panda-64px/south.png` | South-facing sprite (default forward), 92×92 RGBA, 2 KB | ↑ same |
| `pixellab-out/avatar-test-red-panda-64px/north.png` | North-facing sprite, 92×92 RGBA, 2 KB | ↑ same |
| `pixellab-out/web-vision-test.png` | Red panda → chibi pixel-art, 256×256 RGBA, 25 KB | **Browser UI**: `POST /api/vision` via the test page |
| `pixellab-out/test-red-panda.png` | Synthetic 512×512 input (a red panda drawn with Pillow) | Test fixture — NOT generated by PixelLab |

> **Note on canvas size**: PixelLab's 4-dir character comes back as **92×92 RGBA per direction** — the character fits inside a ~64×64 box, the rest is transparent padding for animation headroom. This is documented behavior in `docs/reference/pixellab-api.md`.

To look at the avatar sprites, just open `pixellab-out/avatar-test-red-panda-64px/south.png` in Preview / any image viewer. They'll look small because they're 92 px, but **the browser test page shows them at 4× pixel-perfect upscaling** so the detail is readable.

## 3. 🛠 CLI demo (the underlying binary)

The browser UI uses the same code as this CLI. Useful for batch testing or scripting.

```bash
# 1. Check PixelLab balance (free)
cargo run --bin image2pixel -- balance

# 2. Text → single pixel-art image (sync, ~5s)
cargo run --bin image2pixel -- text \
  "A small orange tabby cat with bright green eyes, sitting upright" \
  --size 256

# 3. Image → single pixel-art image, no LLM (sync, validates PixelLab's "size limit" claim)
cargo run --bin image2pixel -- direct pixellab-out/test-red-panda.png --size 256

# 4. Image → vision → single pixel-art image (sync, ~10s)
cargo run --bin image2pixel -- vision pixellab-out/test-red-panda.png --size 256

# 5. Image → vision → 4-dir character (async, ~60–120s)
cargo run --bin image2pixel -- avatar pixellab-out/test-red-panda.png \
  --size 64 --template mannequin --proportions chibi

# 6. Text-only 4-dir character (no image needed)
cargo run --bin image2pixel -- avatar-text "tiny green dragon with golden eyes" \
  --size 64 --template mannequin
```

Outputs land in `pixellab-out/` by default. Override with `PIXELLAB_OUT=...`.

## 7. ❓ Troubleshooting

- **`RUST_BACKTRACE=1 cargo run --bin pixelart_server`** — if it crashes, get the backtrace.
- **422 from PixelLab** — check the three known live-vs-spec discrepancies in `src/pixelart/mod.rs` (image-to-pixelart needs both `image_size` + `output_size`, character returns `background_job_id` singular, pixon rejects extra fields).
- **`MINIMAX_API_KEY` errors** — make sure the key starts with `sk-cp-`. The base URL is `https://api.minimaxi.com/v1/`.
- **Stuck on "polling" forever** — PixelLab's job ID might have expired (>5 min). Submit a new one.
- **`<think>…</think>` in description** — MiniMax-M3 emits reasoning tokens; `src/pixelart/mod.rs::strip_think()` strips them. If you see them leaking, that function isn't being called.
