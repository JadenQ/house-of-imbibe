## 3. 既有问题（非本次引入，仍未修）

- **禁令 #1 违反持续**：`src/lib.rs::avatar_generate_submit` 仍在 HTTP 路径内 `await` MiniMax vision + PixelLab submit（几十秒阻塞）。应挪进后台 worker。最该早修的一项。
- **job 内存丢**：avatar 生成 job 只在 `Arc<RwLock<HashMap>>`，重启即丢；无 `generation_jobs` 表（review 🔴 #2）。
- **存 URL 不存 key**：`avatars.config_json` 存 PixelLab 外链 rotation URL（会过期裂图 + CORS taint 风险），违 CLAUDE.md「存 key 不存 URL」。修法 = 下载 PNG 到本地 + `AssetStore` + `/api/assets/{key}`（review 🔴 #3）。
- **SQLite FK 未启用**：`migrations/0001_init.sql` 有 `REFERENCES` 但**无 `PRAGMA foreign_keys=ON`**（sqlx 默认关）→ 删 user 不会级联删 session/avatar。`main.rs`/`spawn_app` 连接时应加 `foreign_keys(true)`（sqlx SqliteConnectOptions）。
- **首 admin 并发竞态**：`register` 用 `SELECT COUNT(*) FROM users` 判首用户，两并发注册都可能拿 0 → 两个 admin（review 🟡 #10）。
- **session 无过期/无 Secure**；`create_session` `.expect()` panic；前端轮询无上限（review 🟢/🟡）。
- **先直转冲突**：CLAUDE.md「先尝试 image-to-pixelart 直转」vs 4dir 角色只能文字驱动 → 切片 4 待用户拍板。
